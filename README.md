# SecurePass-PASSWORD-risk-analyzer

OVERVIEW
SecurePass is a python application that analyzes the strength of a password and estimates its security risk. It helps users create stronger passwords by checking common security rules and providing suggestion to the user.

FEATURES:
- Password strength analysis.
- Risk score (0-100)
- Low, Medium and High Risk classification.
- Improvement Suggestions.

Technologies USED:
- Python 3
- Tkinter
- Built in Python functions


How To Run:
1. Open the project folder.
2. Run main.py
3. Enter a password and click analyze.
